# Word banks and compatibility benchmarks

The word lists in `wordlists/` are fixed, open-licensed banks used for
practice and compatibility testing.

`banks.json` defines the bank id, name, description, word list, size, tier,
source ids, licence and SHA-256.

`references/` is for external dictionaries and is not committed. Add a
dictionary locally, then run the scorer. No Plover or other reference data is
shipped with the app.

Bank outlines will be generated by the open dictionary engine. The lists are
input only; the generated `word -> outline` maps are the actual practice banks.

## Compatibility results

The banks are compared with an external Plover-compatible reference. The reference
is not committed. Results are exact signature matches among the words present in
both the bank and the reference. Coverage is shown separately because the
external reference does not contain every generated word.

| Bank | Words | Reference coverage | Exact match | Jaccard |
|---|---:|---:|---:|---:|
| Basics 500 | 500 | 500 / 500 | 324 / 500 = 64.8% | 0.862 |
| Everyday 500 | 500 | 417 / 500 = 83.4% | 218 / 417 = 52.3% | 0.795 |
| Legal 200 | 200 | 83 / 200 = 41.5% | 23 / 83 = 27.7% | 0.630 |
| Business 200 | 200 | 102 / 200 = 51.0% | 28 / 102 = 27.5% | 0.682 |
| General 500 | 500 | 16 / 500 = 3.2% | 8 / 16 = 50.0% | 0.823 |
| Sentence words | 135 | 135 / 135 | 113 / 135 = 83.7% | 0.941 |

The General bank is a random CMUdict sample and the external reference only
contains 16 of its 500 words. Its percentage is not a general accuracy result.

Run a bank score locally with:

```sh
python3 benchmarks/scripts/score.py \
  --generated benchmarks/banks_data/everyday/dictionary.json \
  --bank benchmarks/wordlists/everyday-500.txt \
  --reference benchmarks/references/plover-pro.json \
  --reference-format word2stroke
```
