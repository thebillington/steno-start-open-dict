# Word banks and compatibility benchmarks

The word lists in `wordlists/` are fixed, open-licensed banks used for
practice and compatibility testing.

`banks.json` defines the bank id, name, description, word list, size, tier,
source ids, licence and SHA-256.

`references/` is for external dictionaries and is not committed. Add a
dictionary locally, then run the scorer. No Plover or other reference data is
shipped with the app.

Bank outlines will be generated by the open dictionary engine. The lists are
input only; the generated `word -> outline` maps are the actual practice banks.

## Full bank compatibility

The full reference is an external Plover `main.json`. It is not committed, not
shipped and not used to generate any outline. Every bank word is in the
denominator. A word is exact when the generated stroke sequence matches any
published outline for that word.

| Bank | Words | In reference | Exact, all words | Exact, present |
|---|---:|---:|---:|---:|
| Basics 500 | 500 | 500 | 392 / 500 = 78.4% | 78.4% |
| Everyday 500 | 500 | 500 | 328 / 500 = 65.6% | 65.6% |
| Legal 200 | 200 | 199 | 59 / 200 = 29.5% | 59 / 199 = 29.6% |
| Business 200 | 199 | 197 | 71 / 199 = 35.7% | 71 / 197 = 36.0% |
| General 500 | 500 | 142 | 23 / 500 = 4.6% | 23 / 142 = 16.2% |

The General bank is a random CMUdict sample. 358 of its 500 words are absent
from the Plover reference, so its all-word percentage is not comparable with
the other banks. The bank is a poor compatibility target and a product decision
is needed.

The full machine-readable results are in `results-full.json`. The earlier
500-word teaching-subset comparison is retained in `results.json`; it is a
narrower reference and should not be compared with the full table above.

Run the full scorer locally with:

```sh
python3 benchmarks/scripts/full_compat.py \
  --reference /path/to/main.json \
  --bank benchmarks/banks_data/everyday/dictionary.json \
  --name everyday
```
