# Sources

Allowed inputs:

- CMUdict, BSD-2-Clause, pronunciation only.
- Art of Chording, CC BY-SA 4.0, theory and brief examples.
- Wikipedia Stenotype, CC BY-SA 4.0, layout and chart.
- Plover Wiki, only pages whose licence and provenance are clear and which do not
  reproduce GPL dictionary content.
- Steno Start authored rules, briefs and word list.

Forbidden:

- Plover main.json and derivatives.
- Typey Type and other GPL dictionaries.
- Lapwing dictionary until its licence is clarified.
- StenEd, Magnum, Phoenix or other proprietary dictionaries.
- User-generated dictionaries of unclear provenance.

`sources.json` records the source id, URL, licence, usage and modification status.
