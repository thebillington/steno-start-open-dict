# Contributing

- Dictionary data contributions are accepted under CC BY-SA 4.0.
- Generator code contributions are accepted under MIT.
- Every new or changed entry must update `provenance/entries.json`.
- Do not submit Plover main.json, GPL dictionary data, proprietary dictionaries,
  or data of unclear provenance.
- State whether an entry is copied, adapted, or generated from a named source.
- Run `scripts/check.sh` before opening a pull request.
